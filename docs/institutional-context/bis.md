# BIS Context

NON-NORMATIVE.

BIS work on tokenisation, unified ledgers and wholesale cross-border payments emphasises singleness of money, interoperability, liquidity elasticity, tokenised deposits, central-bank settlement, stablecoins and operational resilience. BIS materials also discuss how fragmented networks can trap liquidity and weaken monetary network effects.

OMST addresses a narrower technical primitive: machine-readable state and transition properties for digital money.
