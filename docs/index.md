# OMST

Open Monetary State & Transition Standard.

OMST is an open standard for describing digital money and determining whether it can satisfy settlement requirements across heterogeneous financial systems.

Same currency denomination does not necessarily imply settlement equivalence. OMST makes those differences explicit through money profiles, settlement profiles, participant profiles, state predicates, requirement sets, evidence policies, transition plans, route explanations, adapter mappings and reproducible settlement-compatibility profiles.

Start with the specification, settlement compatibility chapter, implementer guide, whitepaper, concept chapters and synthetic tokenized-bond DvP case study.
