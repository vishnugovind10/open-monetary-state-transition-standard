# RFC-0022 Compatibility Reason Codes

Status: Draft

Defines stable machine-readable reason codes for settlement compatibility. Implementations should preserve codes exactly so independent systems can compare results.

Initial codes include `ATOMICITY_UNAVAILABLE`, `FINALITY_MISMATCH`, `AVAILABILITY_MISMATCH`, `LATENCY_REQUIREMENT_UNMET`, `LIQUIDITY_INSUFFICIENT`, `LIQUIDITY_EVIDENCE_STALE`, `UNKNOWN_STATE` and `CONFLICTING_EVIDENCE`.
