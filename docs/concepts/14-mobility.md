# Mobility

## Definition

Monetary mobility describes how value can move between instruments, venues or settlement environments.

## Purpose

Return route, conversion cost, liquidity required, latency, finality, constraints, integrity, confidence and evidence.

## Inputs

Source, target, quantity, timestamp, venue and context.

## Outputs

Mobility route and transition analysis.

## State Assumptions

No viable route is a valid analytical result, not an implementation crash.

## Examples

EUR-X to CBM to EUR-Y.

## Non-Examples

Bridge execution or custody movement.

## Failure Modes

Route unavailable, liquidity exceeded, finality degraded or access denied.

## Relationship To Other OMST Concepts

Mobility uses the money graph, relations, liquidity and transition integrity.
