# Overview

## Definition

OMST is a protocol-agnostic standard for digital-money state, transition, evidence and interoperability semantics.

## Purpose

Make monetary transitions machine-readable and testable across heterogeneous financial infrastructures.

## Inputs

Money profiles, capabilities, states, relations, events, evidence and settlement contexts.

## Outputs

Validated transitions, evaluations, routes, integrity findings and conformance results.

## State Assumptions

Unknown data is represented as `UNKNOWN`, not as failure or success.

## Examples

EUR-X to EUR-Y conversion through a central-bank-money anchor.

## Non-Examples

Reserve certification, custody, settlement execution and regulatory classification.

## Failure Modes

Missing evidence, incompatible finality, stale liquidity, route failure and ambiguous state.
