# Security

Report suspected vulnerabilities through private maintainer contact where available. Do not include secrets, private keys, personal data, private URLs, or issuer-confidential data in public issues.

OMST threat categories include state manipulation, event forgery, evidence poisoning, replay attacks, transition ambiguity, oracle dependency, numerical manipulation, route manipulation, graph poisoning, privacy leakage and dependency attacks.

Evidence integrity and transition integrity are separate concerns. A transition can be semantically valid while the evidence supporting it is weak, stale, declared-only or simulated.
