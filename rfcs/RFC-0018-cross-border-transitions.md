# RFC-0018: Cross-Border Transitions

Status: draft

## Abstract

Defines future cross-border monetary transition semantics.

## Motivation

Cross-border settlement can include FX requirements, PvP, sequential FX, netted FX, settlement anchors, jurisdiction references and data constraints.

## Scope

Roadmap in v0.3.

## Terminology

Source currency, target currency, PvP, atomic FX, jurisdiction reference.

## Specification

Future schema.

## Examples

Synthetic EUR-to-non-EUR PvP transition.

## Security Considerations

Sequential FX creates settlement and principal-risk questions.

## Privacy Considerations

Cross-border metadata can reveal sensitive participant information.

## Compatibility

No breaking change.

## Open Questions

Which PvP evidence fields are mandatory?
