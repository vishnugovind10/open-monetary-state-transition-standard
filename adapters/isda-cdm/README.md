# ISDA CDM Conceptual Adapter

CDM describes financial contract and event semantics. OMST describes digital-money state-transition semantics.

This adapter demonstrates conceptual mapping only:

- contract event: `LOSSY`
- settlement obligation: `DERIVED`
- money transition: `DERIVED`
- legal terms: `UNSUPPORTED`

OMST does not replace CDM and this repository does not claim official ISDA endorsement, certification or affiliation.
