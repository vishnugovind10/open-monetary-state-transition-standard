# ISO 20022 Conceptual Adapter

ISO 20022 provides message and data semantics. OMST provides monetary state-transition semantics.

This adapter demonstrates conceptual mapping only:

- amount: `EXACT`
- currency: `EXACT`
- settlement state: `APPROXIMATED`
- finality: `DERIVED`

OMST does not replace ISO 20022 and this repository does not claim official ISO 20022 endorsement, certification or affiliation.
