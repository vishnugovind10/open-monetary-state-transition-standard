# FINOS CDM Conceptual Adapter

FINOS CDM describes financial contract and event semantics. OMST describes digital-money semantics and settlement state transitions.

This adapter demonstrates conceptual mapping only:

- event identifier: `LOSSLESS`
- contractual state: `APPROXIMATED`
- cash settlement leg: `DERIVED`
- money-state evidence: `UNSUPPORTED`

OMST does not replace FINOS CDM and this repository does not claim official FINOS endorsement, certification or affiliation.
